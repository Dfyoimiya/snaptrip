   - 结果：页面自动返回商品列表，列表立即显示编辑后的名称，没有手动刷新。

3. 执行商品删除：
   - 点击编辑后商品的“删除”，完成二次确认。

4. 执行数据库复查：

   - 结果：商品名称为编辑后的名称，价格为 `88.80`，`is_deleted=true`。
   - 再通过商品列表接口按名称查询。
   - 结果：返回 `total=0`，软删除商品不会再次出现在后台列表。

5. 执行接口级 CRUD 闭环：
   - 调用 FastAPI 创建商品，返回有效商品 UUID 和 1 条 SKU。
   - 调用编辑接口，名称和价格更新为新值。
   - 调用详情接口，读取到更新后的名称、价格和库存。
   - 调用删除接口，再次查询列表。
   - 结果：新增、编辑、详情和删除均返回 `code=0`；删除后列表不包含该商品。
